Step 2

uv

uv is a fast Python package manager. It handles both the Python version and all dependencies — no separate Python install needed.

macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
Windows PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Reference: docs.astral.sh/uv/getting-started/installation/

After installing, close and reopen your terminal. Then verify uv:

# verify uv
uv --version
Using conda or another package manager?
That is totally fine for this session. Just make sure your environment has numpy, matplotlib, jupyter, and ipykernel installed so the notebooks run correctly.

AI Coding Agents

GitHub Copilot · Codex · Claude Code

Concepts

What Is an AI Coding Agent?

Read
Understands context
Reads your files, project structure, and instructions to understand what you're working on.
Suggest
Proposes changes
Generates code completions, edits, or full implementations — inline or in chat.
Act
Can run commands
Advanced agents can execute shell commands, run tests, and iterate until the task is done.
Examples of AI coding agents
Claude Code from Anthropic, Codex from OpenAI, and other agent-style tools like GitHub Copilot agent mode. They all help read files, make edits, and run commands inside your project.
Primary tool for this tutorial

GitHub Copilot

Copilot is GitHub's AI assistant, integrated directly into VS Code. It helps with code completions, chat-based Q&A, and agentic edits — all without leaving the editor.

  • Inline completions — code suggestions as you type
  • Copilot Chat — ask questions, get explanations
  • Agent mode — multi-step edits across files

Advanced features

Instruction Files

Instruction files define rules for how Copilot should behave in your project — coding style, what packages to use, how to structure answers, whether to give hints or full solutions.

.github/copilot-instructions.md
General repository rules — applies to all files. Think before coding, simplicity first, surgical changes.
.github/instructions/task1-notebook.instructions.md
applyTo: "task1/**/*.ipynb"
Task-specific instructions — applies only to files matching the pattern.
Which instruction file is used here?
The used instruction file is a slightly adapted version of a popular instruction file that is based on work by the researcher Andrej Karpathy. Feel free to change it to your liking!
More info
  • →For more on custom instructions in GitHub Copilot, see the docs.
  • →Claude Code uses a similar CLAUDE.md-based setup. See the docs.
  • →Codex uses AGENTS.md files. See the docs.
Advanced features

Plan Mode

Plan mode makes Copilot think before it acts. It analyzes the task and creates a step-by-step plan — but does not edit any files until you approve.

1
You describe the task
in Copilot Chat
2
Copilot analyses and proposes a plan
No files are touched yet
3
You review & approve
Copilot executes once confirmed
How to activate
Open Copilot Chat → click the mode dropdown → select Plan.
When to use it
Use plan mode when you're thinking about a complex task that involves multiple steps or files. You can review the plan and give feedback before any changes are made. It is also commonly used with a more expensive model, while the implementation is done with a cheaper one.
